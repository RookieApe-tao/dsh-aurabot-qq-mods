# 查群成员（member-info）

问她「这个人是谁」，她能答上来了。

查某个群里某位成员的身份：**群角色**（群主 / 管理员 / 普通成员）、**群名片**、**专属头衔**、
**加群时间**、**Q 龄和 QQ 等级**、**群等级**、**最后发言时间**，被禁言的会单独标出来。

## 解决什么问题

以前群里有人问「高 2401 班工作群这个人是谁」，她只能含糊回避——手里没有查人的手段。
装上这个模块后，她会自己去查，然后照实回答。

## 怎么用

### 聊天里（她自动判断）

直接问她就行，不用记命令：

> 「这个人是谁？」（在群里问，默认查当前群）
> 「2384750291 是管理吗？」
> 「他什么时候进的群？」

她用工具 `member_info` 去查，参数：

| 参数 | 必填 | 说明 |
|---|---|---|
| `userId` | ✅ | 要查的人的 QQ 号（纯数字） |
| `groupId` | — | 群号；**不填就是当前这个群** |

### 主人命令（手动查）

```
/查人 QQ号
/查人 QQ号 群号
```

别名：`/查成员`、`/成员`。命令只认主人，别人发 `/查人` 会被当普通消息。

例：

```
/查人 1591261865
/查人 1591261865 1106441882
```

### 面板设置

「已安装」→ 这个模块，两个开关：

| 设置项 | 默认值 | 说明 |
|---|---|---|
| **显示最后发言时间** | 开 | 关掉后只报身份和加群时间，少一行 |
| **显示 Q 龄和 QQ 等级** | 开 | 有些人不喜欢被扒 Q 龄，可以关掉 |

两个开关都是**实时生效**，改完不用重载模块。

## 会访问哪些网址

**不访问任何外部网址。** 一个外部请求都没有。

数据全部来自**本机 OneBot 网关**（就是 Aurabot 连的那个 SnowLuma，默认 `127.0.0.1:3000` / `127.0.0.1:3001`），
调用的是这两个接口：

| OneBot 接口 | 用途 |
|---|---|
| `get_group_member_info` | 成员资料（角色、名片、头衔、加群时间、Q 龄……） |
| `get_group_info` | 群名（查不到就少一行，不影响结果） |

所以 `module.json` 里的 `capabilities` 是**空数组**——没有声明 `network`，因为确实不联网；
也不读写文件，没有声明 `filesystem`。

## 安装

把整个 `member-info/` 文件夹放进 Aurabot 的模块目录：

```
plugins-data/aurabot/modules/member-info/
├── module.json
├── index.mjs
├── lib/
│   ├── format.mjs      纯格式化（角色翻译、时间、时长）
│   └── query.mjs       查询封装（参数校验、错误翻译）
├── test/
│   └── format.test.mjs 纯函数单测
├── README.md
└── LICENSE
```

放进去几秒内自动加载，不用重启。「已安装」页能看到 `member-info`。

需要 Aurabot 插件 `1.2.0` 以上、模块接口 `api: 1`。

## 测试

测试只覆盖**纯函数**（不联网、不需要 Aurabot），用 Node 自带的 test runner：

```bash
cd member-info
node --test test/
```

11 个用例，覆盖角色翻译、时间格式化、时长进位、参数校验、错误翻译、资料拼装。

## 已知边界

- 机器人必须**在那个群里**，才查得到成员资料；不在群里会返回「没权限」。
- 只查**群成员**。不在群里的人查不到（OneBot 的 `get_stranger_info` 需要额外权限，这里没用）。
- 成员资料里的 `age` / `sex` 字段协议端基本不返回真值（都是 `unknown` / `0`），所以不展示，免得误导。
