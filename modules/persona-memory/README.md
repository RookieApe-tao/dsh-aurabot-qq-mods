# 人设记忆管理

作者 **Yobak** · 管理 · MIT

整理长期聊天与角色经历，按需回忆、减少重复上下文。可以查看、编辑和追溯记忆来源，也可以清理指定互动范围后重新开始，保留人设和设置。

**与「跨会话记忆」（`history-vault`）互斥。** 关闭增强记忆后，适配后的原生记忆可接续同一份档案。已验证的预算管家 `1.2.0` 可共用。

## 安装前置条件

这份源码是市场评审稿，沿用 `0.1.0-beta.9` 手动测试版的记忆实现。完整测试环境为 Aurabot `1.3.0-beta.1`、DSH `0.2.0-rc.2`、Node.js `24.18.0` 起的 24.x，另需安装与这两个宿主版本匹配的适配。

市场安装器只部署模块文件。当前原版宿主没有所需的记忆桥接，请在宿主接入完成后再发布市场版。模块的预检会拒绝在缺少适配时启用。

## 使用

1. 打开「人设记忆管理」查看预检。模块默认关闭。预检通过后，可选择接续旧资料或保留人设重新开始。
2. 在「记忆 / 人物」查看来源、纠正内容、固定重要约定或忘记不再需要的资料。日常聊天优先取相关回忆，久远普通经历优先取已有概括。
3. 重置前先预览角色和聊天范围。会清除该范围共享档案里的原生与增强互动记忆，可将有明确归属的旧窗口移出左侧。底层 DSH 日志保留，旧上下文不再参与新互动。

增强整理按新增内容分批调用 DSH 已配置的模型服务。有独立的次数和用量上限。实际费用取决于所用模型、会话内容和其他玩法。原生向量检索及重排仍有接续限制。

## 权限和数据

归档与检索在本机处理。模块读写本地记忆库和模块设置，使用 Aurabot 内部接口；旧资料接续前需要确认归属。整理时将选定文本发送到 DSH 中用户配置的模型服务，人物头像由浏览器访问 `https://q1.qlogo.cn`，加载失败时显示名字首字。
